# X-Rite Color profiles
These are stock icm profiles from x-rite color assistant for anyone how are unable to restore it from x-rite color assistant.
- **Model - Lenovo legion 5 gen10**
- **Display - 2560x1600, 15.1-inch, oled display, x-rite color asistant.**

# Installation #
Copy Color profiles and paste it in C:\\Windows\System32\spool\drivers\color folder.
